# Briefing – 2badi-test

## Purpose
This is a test repository for the **Data as a Service** course (Thomas More, 2026–2027).
It is used to practise working with Git and GitHub before starting on the real project.

## Goals
- Learn the basic Git workflow: `clone`, `add`, `commit`, `push`, `pull`
- Practise working with branches and merging
- Get used to writing clear commit messages

## Workflow
1. Pull the latest changes: `git pull`
2. Make your changes
3. Stage and commit: `git add .` then `git commit -m "short description"`
4. Push to the remote: `git push`
